# Ray Revello — Personal Website

A single-file résumé website for **Ray Revello** — director, filmmaker, and film curator based in San Francisco, CA (also Austin, TX).

## Contents
- `index.html` — the entire site. Self-contained: all CSS, JavaScript, and the hero portrait (base64-embedded) are inline, with **no external dependencies**. Open it directly in any browser.

## Features
- Full-height hero with framed portrait, name, and tagline
- About section with an "At a Glance" facts panel (craft + genre chips)
- Selected filmography as a responsive card grid (2009–2026)
- Contact links: IMDb, Dollars & Donuts, Instagram
- Three live-switchable themes (Noir / Modern / Bold) via the top-right switcher
- Fully responsive with smooth scroll-reveal animations

The site is a single static file. To publish it live later, enable GitHub Pages
(Settings → Pages → deploy from `main` / root) — `index.html` is already the entry point.
